# SiteLaser

대지를 선택하거나 도면 파일을 올리면, 레이저 커팅용 지형판과 건물 모형을 만들어 주는 웹 도구입니다. 설치 없이 브라우저에서 바로 실행되고, 파일은 서버로 보내지 않고 내 컴퓨터 안에서만 처리됩니다.

**사이트:** https://jae-archi.github.io/sitelaser/

## 사용법

1. **입력** 중 하나를 고릅니다.
   - **IGN**: 프랑스 주소·장소를 검색하고 범위를 정한 뒤 *범위 내 건물 조회* → 포함할 건물 선택.
   - **파일 업로드**: DXF(ASCII) 또는 3DM. 외곽선은 `BOUNDARY` 레이어에 닫힌 선 하나, 등고선은 `CONTOUR` 레이어(높이 = 선의 Z/elevation).
2. 축척(1:N), 판 두께(mm), 지형 높이 간격(m), 용지를 정합니다.
3. **지형판 생성** → 판별 2D 도면과 3D 적층 모형을 확인합니다.
4. **내보내기 ZIP**: 판별 SVG·DXF, 건물 STL, Rhino 3DM, 좌표 정보.

## 참고

- 처음 실행할 때 브라우저용 Python(Pyodide)을 불러오느라 10~20초 걸립니다.
- IGN 표고 조회는 범위와 샘플 간격에 따라 수십 초 걸릴 수 있습니다.
- 높이 정보가 없는 IGN 건물은 자동으로 제외됩니다.
- 제작 전 절단선·각인선, 단위, 공차를 꼭 확인하세요.
